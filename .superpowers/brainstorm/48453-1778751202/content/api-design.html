API 设计

两套 API：商户端（API Key 认证）+ 管理后台（JWT 认证）

▌ pay-api  ·  商户端 REST API
认证： Authorization: Basic base64(sk_live_xxx:)
API Key 作为用户名，密码留空，标准 HTTP Basic Auth
CHARGES 支付订单
POST /v1/charges 创建支付订单
GET /v1/charges/:id 查询订单
GET /v1/charges 订单列表（分页）
REFUNDS 退款
POST /v1/charges/:id/refunds 发起退款
GET /v1/charges/:id/refunds 退款列表
GET /v1/refunds/:id 查询退款详情
NOTIFY 渠道回调（无需认证）
POST /v1/notify/wechat/:appId 微信异步通知
POST /v1/notify/alipay/:appId 支付宝异步通知
POST /v1/charges 请求示例
{
  "order_no": "ORDER_20240515_001",
  "channel": "wechat_jsapi",
  "amount": 9900,
  "currency": "cny",
  "subject": "商品名称",
  "body": "商品描述",
  "client_ip": "192.168.1.1",
  "time_expire": 1800,
  "channel_extra": { "open_id": "oUpF8xxx" },
  "metadata": { "user_id": "U123" }
}
响应（返回支付凭证）
{
  "id": "ch_abcdef123456",
  "object": "charge",
  "status": "pending",
  "paid": false,
  "amount": 9900,
  "credential": {
    "wechat_jsapi": {
      "appId": "wxabc",
      "timeStamp": "1715700000",
      "nonceStr": "xxx",
      "package": "prepay_id=wx...",
      "signType": "RSA",
      "paySign": "xxx"
    }
  }
}
▌ pay-admin-api  ·  管理后台 API
认证： Authorization: Bearer <JWT>
操作员登录后获取 JWT，有效期 8h，刷新 Token 有效期 7d
AUTH 认证
POST /admin/v1/auth/login
POST /admin/v1/auth/refresh
MERCHANTS / APPS / CHANNELS
GET /admin/v1/merchants
POST /admin/v1/merchants
GET /admin/v1/merchants/:id/apps
POST /admin/v1/merchants/:id/apps
GET /admin/v1/apps/:id/channels
PUT /admin/v1/apps/:id/channels/:ch
ORDERS / REFUNDS / RECONCILE
GET /admin/v1/charges 含筛选/分页
GET /admin/v1/refunds
GET /admin/v1/reconcile
POST /admin/v1/reconcile/trigger 手动触发
OPERATORS 操作员管理
GET /admin/v1/operators
POST /admin/v1/operators
PUT /admin/v1/operators/:id/permissions
OpenSpec 文档：所有端点通过 springdoc-openapi 自动生成，暴露在 /v3/api-docs，Swagger UI 在 /swagger-ui.html。 生产环境通过配置关闭 Swagger UI 访问。
