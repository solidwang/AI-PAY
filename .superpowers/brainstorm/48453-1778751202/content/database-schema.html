数据库设计（MySQL 8）

10 张核心表，覆盖四层账户体系 + 交易 + 权限 + 对账

▌ 账户体系（四层）
merchant 商户
id bigint PK
merchant_no varchar UNIQUE
name varchar
status tinyint
contact_email varchar
contact_phone varchar
created_at, updated_at
→
app 应用
id bigint PK
app_id varchar UNIQUE
merchant_id bigint FK
name varchar
live_key varchar 加密
test_key varchar 加密
status tinyint
created_at, updated_at
→
channel_config 渠道配置
id bigint PK
app_id bigint FK
channel varchar 枚举
config_json text AES加密
存 mch_id/appid/key/cert
status tinyint
created_at, updated_at
＋
operator 操作员
id bigint PK
merchant_id bigint FK
username varchar UNIQUE
password_hash varchar
real_name varchar
is_admin boolean
status tinyint
created_at, updated_at
→
operator_permission 权限
id bigint PK
operator_id bigint FK
module varchar
orders/refunds/channels
reconcile/apps/operators
can_view boolean
can_operate boolean
▌ 交易流水
charge 支付订单
id bigint PK
charge_id varchar ch_xxx UNIQUE
app_id bigint FK
merchant_id bigint
out_trade_no varchar 商户单号
channel varchar 枚举
amount int 分
subject, body varchar
status varchar 状态机
paid boolean · paid_at datetime
time_expire datetime
transaction_no varchar 渠道单号
channel_extra json openid等
credential json 支付凭证
amount_refunded int
metadata json
created_at, updated_at
→
refund 退款单
id bigint PK
refund_id varchar re_xxx UNIQUE
charge_id varchar FK
app_id, merchant_id bigint
out_refund_no varchar
amount int 分
description varchar
status varchar
transaction_no varchar
failure_code, failure_msg
succeed_at datetime
created_at, updated_at
＋
notify_record 回调幂等
id bigint PK
notify_key varchar UNIQUE
channel+transaction_no
charge_id varchar
channel varchar
raw_body text
status varchar
process_count int
created_at, updated_at
＋
reconcile_record 对账
id bigint PK
app_id bigint FK
merchant_id bigint
channel varchar
reconcile_date date
status varchar
total_count, total_amount
matched_count int
unmatched_count int
created_at, updated_at
charge 订单状态机： CREATED  →  PENDING  →  PAID
                   ↓ (超时)      ↓ (全额退款)
                 EXPIRED     REFUNDED   |   渠道枚举： wechat_jsapi · wechat_h5 · alipay_wap   |   权限模块： orders · refunds · channels · reconcile · apps · operators
